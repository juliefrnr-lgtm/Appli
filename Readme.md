
# Let's Trail 🏃‍♀️

Application de suivi et de planification d'entraînement running et trail.

L'objectif : créer un espace personnel pour suivre ses activités, organiser ses entraînements et préparer ses prochains défis sportifs.

## Fonctionnalités

- Tableau de bord personnalisé
- Calendrier d'entraînement
- Historique des activités
- Synchronisation Garmin
- Suivi des statistiques et de la progression
- Préparation des objectifs sportifs
- Gestion de plusieurs profils de coureurs à terme

## Technologies

- Next.js
- React
- TypeScript
- CSS
- API Garmin (intégration à venir)

## Installation

```bash
npm install
npm run dev
```

L'application sera accessible sur http://localhost:3000.
